# CodeAlpha Python Programming Internship Projects

This repository contains four beginner-friendly Python projects based on the CodeAlpha Python Programming Tasks & Instructions.

## Projects included
1. **Hangman Game** — guess a hidden word with up to 6 incorrect guesses.
2. **Stock Portfolio Tracker** — calculate investment value using a predefined stock-price dictionary.
3. **Task Automation Scripts** — includes:
   - Move `.jpg` files from one folder to another.
   - Extract email addresses from a text file.
4. **Basic Chatbot** — rule-based chatbot with simple predefined replies.

## Requirements
- Python 3.8 or newer
- No third-party packages are required.

## Run a project
Open a terminal in this repository folder and run one of the following commands:

```bash
python task1_hangman/hangman.py
python task2_stock_portfolio/stock_portfolio.py
python task3_automation/move_jpg_files.py
python task3_automation/extract_emails.py
python task4_chatbot/chatbot.py
```

On some systems, use `python3` instead of `python`.

## Notes
- The stock prices in this beginner project are sample hardcoded values, not live market prices.
- For the file automation scripts, test using a sample folder and sample text file first.
- The webpage-scraping option from the task brief is not included because the other two automation examples cover the task's suggested scope without requiring network access.
